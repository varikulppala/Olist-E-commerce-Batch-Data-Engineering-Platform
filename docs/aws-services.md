# AWS Services

## Overview

This project uses AWS services for object storage, batch processing, orchestration, monitoring, auditing, and infrastructure management.

The implemented AWS flow is:

**S3 Raw Data → AWS Glue ETL → S3 Processed Data**

Batch orchestration is handled through:

**EventBridge Scheduler → Lambda → AWS Glue**

Downstream analytical processing is performed in Databricks.

---

## Amazon S3

Amazon S3 is the project's object-storage layer.

### Bucket

- Bucket: `olist-aws-batch-data-platform-adhi-2026`
- Region: `ap-south-1` (Mumbai)

The bucket stores the raw and processed stages of the Olist batch pipeline.

### Security and configuration

The bucket was validated with:

- Versioning enabled
- Public access blocked
- Server-side encryption using SSE-S3 (`AES256`)
- S3 Bucket Key enabled

The raw layer contains the source Olist dataset, while the processed layer contains output generated by the AWS Glue ETL job.

---

## AWS Glue

AWS Glue provides the data catalog and batch ETL processing layer.

### Glue Data Catalog

The Glue Data Catalog was used to register and inspect the Olist datasets and support schema-aware data processing.

Athena was used during the data-platform setup for catalog/query validation.

### Glue ETL Job

The implemented ETL job is:

`olist-raw-to-processed-etl`

Configuration validated during the project:

- Glue version: 5.1
- Worker type: G.1X
- Number of workers: 2
- Execution mode: STANDARD
- Maximum concurrent runs: 1
- Timeout: 480 minutes
- Maximum retries: 0
- ETL implementation: PySpark

The Glue script is stored in the AWS Glue assets location:

`s3://aws-glue-assets-970722351160-ap-south-1/scripts/olist-raw-to-processed-etl.py`

The job reads raw data from S3, performs the configured transformations, and writes processed data back to S3.

The latest validated Glue execution completed successfully.

## Amazon EventBridge Scheduler

EventBridge Scheduler provides the daily batch trigger.

### Schedule

- Name: `olist-batch-daily-schedule`
- Schedule: `cron(0 9 * * ? *)`
- Time zone: `Asia/Calcutta`
- State: Enabled
- Target: `olist-batch-orchestrator` Lambda function

The schedule triggers the orchestration Lambda every day at 09:00 in the configured time zone.

---

## AWS Lambda

AWS Lambda provides the lightweight orchestration entry point.

### Function

- Name: `olist-batch-orchestrator`
- Runtime: Python 3.14
- Handler: `lambda_function.lambda_handler`
- Memory: 128 MB
- Timeout: 3 seconds
- Architecture: x86_64

The Lambda function starts the AWS Glue ETL job.

Manual invocation was validated successfully, returning a response indicating that the Glue job was started and providing the Glue run identifier.

This keeps orchestration separate from the ETL workload itself.

---

## Amazon CloudWatch

CloudWatch provides operational monitoring for the AWS batch pipeline.

It is used for:

- Lambda execution logs
- Glue job logs
- Glue execution metrics
- Troubleshooting failed or unexpected executions

Lambda invocation and Glue execution logs were validated during pipeline testing.

---

## AWS CloudTrail

AWS CloudTrail provides API activity auditing for the AWS environment.

It supports operational governance by recording AWS API activity that can be reviewed when investigating infrastructure or service changes.

---

## AWS IAM

AWS Identity and Access Management (IAM) controls permissions for the project's AWS services.

The pipeline uses service roles for AWS Glue, Lambda, and EventBridge Scheduler so that each service can perform its required operations without using personal credentials inside the workload.

Relevant service roles were validated during deployment.

---

## AWS Secrets Manager

AWS Secrets Manager is included as the project's secure mechanism for storing sensitive credentials when application or analytics integrations require them.

Sensitive credentials should not be committed to Git repositories, source files, or Terraform configuration.

## Terraform

Terraform is used for infrastructure-as-code management of selected AWS resources.

The current Terraform configuration manages the implemented S3 and AWS Glue infrastructure.

Validated Terraform operations include:

- `terraform fmt`
- `terraform validate`
- `terraform plan`

The current plan reports no pending infrastructure changes.

Lambda and EventBridge Scheduler are not currently managed by the Terraform configuration and should not be represented as Terraform-managed resources unless explicitly added later.

## AWS Role in the Overall Architecture

The AWS portion of the platform provides the durable storage, ingestion, ETL, and batch-orchestration foundation:

```text
Olist Dataset
     |
     v
Amazon S3 - Raw
     |
     v
AWS Glue Data Catalog / ETL
     |
     v
Amazon S3 - Processed
     |
     v
Databricks Bronze / Silver / Gold
     |
     v
Databricks SQL + dbt
     |
     v
Apache Superset
```

The scheduled execution path is:

```text
EventBridge Scheduler
        |
        v
AWS Lambda
        |
        v
AWS Glue ETL
        |
        v
Amazon S3 Processed
```

CloudWatch, CloudTrail, IAM, and Terraform provide monitoring, auditing, access control, and infrastructure management around the pipeline.
